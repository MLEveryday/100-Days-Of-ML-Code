## 学习目标

区分线性得分、概率和类别；前置：函数与指数。

## 核心说明

逻辑回归先计算 z=wᵀx+b，再用 sigmoid(z)=1/(1+exp(-z)) 映射到 (0,1)。概率不是类别；设阈值 t 后才可把 p≥t 判为正类。默认 0.5 并不适合所有业务，漏判与误判成本会影响阈值。

名称包含“回归”，但这里解决分类问题。线性的是输入到得分 z 的关系，而概率随输入非线性变化。特征变换后边界也不一定在原空间是直线。

## 最小示例

环境见[安装与运行](../setup.md)。下列代码块可作为独立单元运行。

```python
import numpy as np
z = np.array([-2., 0., 2.])
p = np.exp(-np.logaddexp(0, -z))
print(p)
print(p >= 0.5)
```

## 结果解读

三个概率约为 0.119、0.5、0.881。它们可用于排序或决策，不必总变成 0/1。

## 练习

计算阈值从 0.5 改为 0.9 时的预测；解释为什么无法单凭概率判断阈值是否合理。实现见 Day 6。
