## 学习目标

理解分隔超平面及最近点的重要性。

## 核心说明

超平面满足 wᵀx+b=0。点到超平面的几何距离为 |wᵀx+b|/||w||。硬间隔问题的支持向量位于间隔边界上；软间隔问题还可能包括间隔内乃至误分类的点，它们参与决定边界。线性可分数据可能有很多分隔线，最大间隔原则选择其中一种。

现实数据常有重叠和噪声，软间隔允许一定违例。不要把“线性相关”当“线性可分”：前者通常描述数值关系，后者描述类别是否可由超平面分开。

## 最小示例

环境见[安装与运行](../setup.md)。下列代码块可作为独立单元运行。

```python
import numpy as np
w = np.array([1., -1.])
b = 0.
X = np.array([[2., 0.], [1., 1.], [0., 2.]])
print("scores", X @ w + b)
print("distances", np.abs(X @ w+b)/np.linalg.norm(w))
```

## 结果解读

中间的点位于边界上，另外两点在不同侧且距离相同。

## 练习

同时将 w 和 b 乘 10，解释为何符号分类和几何距离不变。
