# Day 28：练习提示与参考答案

[返回本课](../../docs/lessons/day-28.md) · [学习路线](../learning-paths.md)

先完成本课练习，再按需展开。开放实验按方法和记录自检，不以“分数越高”作为唯一标准。

<details>
<summary>第一层：提示</summary>

叉积的 z 分量是 ux·vy−uy·vx。

</details>

<details>
<summary>第二层：参考解法</summary>

u=[1,2,0]、v=[2,1,0]，u×v=[0,0,−3]，与两者点积均为 0。u 与 2u 长度不同但余弦为 1；u 与 −u 的余弦为 −1。

</details>

<details>
<summary>第三层：自检标准</summary>

排除零向量；平行向量叉积为零，此时不具有唯一法向方向。

</details>
