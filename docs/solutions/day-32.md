# Day 32：练习提示与参考答案

[返回本课](../../docs/lessons/day-32.md) · [学习路线](../learning-paths.md)

先完成本课练习，再按需展开。开放实验按方法和记录自检，不以“分数越高”作为唯一标准。

<details>
<summary>第一层：提示</summary>

找驻点为极大值或拐点的函数。

</details>

<details>
<summary>第二层：参考解法</summary>

f(x)=−x² 在 0 梯度为零但为极大值；f(x)=x³ 在 0 梯度为零但不是极值。梯度给一阶下降方向，链式法则连接复合导数，Hessian/二阶导反映局部曲率。

</details>

<details>
<summary>第三层：自检标准</summary>

梯度为零只是候选驻点；不能直接宣布已找到最小损失。

</details>
